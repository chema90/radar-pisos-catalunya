# v39 - Móvil y publicación web

- En móvil el mapa pasa a ser la primera superficie de trabajo: se abre antes que la lista y conserva los controles de selección, capas y pisos vistos.
- Cabecera y buscador se mantienen a mano al desplazarse, con áreas táctiles más cómodas y respeto del borde seguro de teléfonos modernos.
- Se mantiene la interfaz completa: no se eliminan capas, desglose, selección múltiple, favoritos ni registro de pisos.
- Se prepara GitHub Pages: la aplicación se compila con la ruta correcta del repositorio y se publica automáticamente al actualizar la rama `main`.
- Se añaden metadatos de instalación web para que un navegador móvil pueda añadir el Radar a su pantalla de inicio.
